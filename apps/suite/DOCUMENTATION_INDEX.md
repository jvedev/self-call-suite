## 🆘 Need Help?

### Issue: Documentation doesn't answer my question
→ Check [IMPLEMENTATION_GUIDE.md](./IMPLEMENTATION_GUIDE.md) - Troubleshooting
→ Look at similar components in `src/` for examples

### Issue: Can't find a file
→ Check [DIRECTORY_STRUCTURE.md](./DIRECTORY_STRUCTURE.md)
→ Use Ctrl+P in VS Code to search

### Issue: TypeScript error
→ Check tsconfig.json for settings
→ Read error message carefully
→ Check types in `src/types/index.ts`

### Issue: Component not rendering
→ Check browser console (F12)
→ Verify component is imported in `main.ts`
→ Check customElements.define() call

### Issue: Styling looks wrong
→ Check [README.md](./README.md) - Web Component Sizing
→ Verify CSS imports with `?raw` suffix
→ Check shared CSS in `src/styles/shared.css`
